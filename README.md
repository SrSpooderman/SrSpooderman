## About Me

I'm a software developer focused on **backend engineering, API development, databases, and software architecture**.

I enjoy taking projects beyond the code editor: designing their architecture, developing their features, containerizing services, configuring infrastructure, and maintaining the systems they run on.

My main ecosystem revolves around **Python, FastAPI, SQL, Docker, and Linux**, while I also work with React and TypeScript when a project needs a frontend.

I maintain my own self-hosted environment, where I experiment with authentication, deployment automation, monitoring, and service integration.

I care about writing software that's understandable, maintainable, and built to evolve.

### 02. Cliponomicon API

**Video management and asynchronous processing platform**

A modular backend designed to handle video uploads, processing, storage, and delivery, alongside a dedicated administration interface.

**Engineering focus**
- Hexagonal architecture with domain, application, entrypoints, and infrastructure layers.
- Asynchronous video processing using Redis and RQ.
- FFmpeg transcoding and thumbnail generation.
- JWT authentication, role-based access, and optional OIDC integration.
- Idempotent uploads, processing retries, and operational logging.
- Administrative dashboard for users, videos, and worker monitoring.

**Stack:** FastAPI · MySQL · SQLAlchemy · Redis · RQ · FFmpeg · React · TypeScript · Docker

[**Explore Repository →**](https://github.com/SrSpooderman/CliponomiconAPI)

### 04. SpiderToMP3

**Cross-platform desktop audio application**

A Python desktop application for downloading and converting supported media sources into audio files.

**Engineering focus**
- Desktop GUI development with Qt/PySide6.
- Download queue management, persistence, cancellation, and retries.
- Integration with yt-dlp, FFmpeg, MusicBrainz, and podcast RSS feeds.
- Playlist import/export and metadata management.
- Automated testing and GitHub Actions workflows.
- Executable packaging and update management for Linux and Windows.

**Stack:** Python · PySide6 · yt-dlp · FFmpeg · GitHub Actions

[**Explore Repository →**](https://github.com/SrSpooderman/SpiderToMP3)
